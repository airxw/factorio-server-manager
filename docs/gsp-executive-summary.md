# GSP — Executive Summary（一页）

> **GameServer Panel** · B2B2C 商业化 SaaS 操作系统 · v4.32.0 · 2026-07-29

## 一句话

GSP 解决了游戏私服生态的**三方痛点**——服主为爱发电开服没钱赚、玩家有钱没地方消费、平台赚不到增长红利。平台**创造三方共赢的市场**：赋能服主赚钱（卖算力 + 变现工具 + 资金通道），从增长交易里分一杯羹。**服主帮平台运营，服主赚钱了平台才能赚钱。** 用 **14 天 107 个版本**证明：**单人 + AI 多智能体协作规范**也能造出商业化 SaaS 操作系统。

## 三大差异化亮点

### 1. B2B2C 三角角色模型（行业首创）

把游戏私服生态抽象成 **供应链—零售商—消费者** 三角：

- **系统管理员（平台方）**= 供应链，提供算力 + 全局资产标品
- **实例管理员（服主）**= 零售商，零代码改价即营业，高阶用户可用 RCON 沙箱做 UGC
- **普通用户（玩家）**= 自助充值门户，账号绑定 → 充值 → 物品/特权自动下发

竞品（Pterodactyl / AMP / LinuxGSM）全部停在"运维层"，**没有商业化层**。

### 2. 三大技术护城河

| 护城河 | 实现 | 竞品做不到的原因 |
|--------|------|----------------|
| **Pack 配置驱动** | 一份 `pack.yaml` 描述游戏全部能力，业务代码零改动 | 12 款游戏开箱即用，新增游戏边际成本趋零 |
| **RCON 指令沙箱** | `IExecutionEngine` 白名单过滤防注入 | Tebex 等外挂商店只能信任服主输入 |
| **Panel-Daemon 主从集群** | Master + N 个 Slave 节点，WebSocket 长连接 | 一台 Panel 管理多台物理机 |

### 3. 商业模式：创造三方共赢的市场（最精彩的部分）

平台不是"卖工具收订阅费"的收割者，而是**市场制造者（market-maker）**——让原本不存在的交易发生：

| 角色 | 传统面板时代 | GSP 时代 |
|------|-------------|---------|
| **服主** | 为爱发电，自掏腰包，烧不起就关服 | 可持续经营的小商家，平台提供算力+变现工具+资金通道 |
| **玩家** | 有钱没处花，只能去灰色平台买 CDK | 自助充值门户，特权/道具即时到账，资金安全 |
| **平台** | 收订阅费，赚不到增长红利 | 从增长交易里分一杯羹（卖服务器+提现抽成） |

**三条收入流**：

| 收入流 | 谁付钱 | 模式 | 落地状态 |
|--------|--------|------|---------|
| ① **服务器销售** | 服主→平台 | VPS 式预付费（micro/small/medium/large/xlarge × 月/季/半年/年） | 已落地 v4.29.x |
| ② **提现分成** | 服主→平台 | 提现码审批流 + 7 天过期自动退费，平台抽成 | 已落地 v4.29.0 |
| ③ **Pack 市场抽成** | 开发者→平台 | 社区上传 Pack，平台抽 10-15% | 未来规划 |

**核心逻辑**：服主从玩家赚到钱 → 有动力持续运营 → 服务质量提升 → 玩家留存消费 → 服主收入增长 → 扩实例 + 提现 → **平台两条收入流都增长**。

**核心结论**：**服主帮平台运营，服主赚钱了平台才能赚钱。** GSP = **游戏私服生态的 YouTube + Shopify**——让创作者/小商家从"为爱发电"变成"可持续经营"，平台从增长的市场里分一杯羹。

## 开发方法论：单人 + AI 多智能体协作规范

这不是 PPT，是已落地的工程方法论，由 5 份核心规则文件定义（[`.trae/rules/`](../.trae/rules/)）：

- **8 阶段流水线**（S0-S7，含 2 个 [V] 价值判断节点）
- **EC-7 信号协议**（L1/L2/L3 三级，人类不填空 LLM 给选项）
- **GN-004 独立审查**（不可由主 Agent 自扮，每个 Spec/Plan ≥ 1 次）
- **s0402 三重测试闸门**（单测→E2E→Mock 回归，顺序固定不可跳关）
- **三层契约**（数据/接口/配置 + public/ 目录显式保护）
- **Subagent 调度台账**（actual agent id + 第二落点 + 失败回退点）

人机权责二分：**AI 负责 80% 执行**（代码/测试/部署/审查），**人类只做 20% 决策**（价值判断/不可逆锁定/契约变更）。
