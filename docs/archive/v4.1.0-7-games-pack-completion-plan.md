### A3. 新增 bootstrap 辅助函数：`writeDstClusterFiles`

为 DST 写默认的 cluster 配置文件（位于 `<workdir>/Cluster_1/`）：

- `cluster.ini`：集群级配置（game_mode=survival, max_players=16, pvp=false, pause_when_empty=true, tick_rate=60, console_enabled=true）
- `cluster_token.txt`：占位文件，写入 `__REPLACE_WITH_YOUR_KLEI_TOKEN__`，启动前必须替换
- `Master/server.ini`：Master shard 配置（server_port={{game_port}}, is_master=true, master_server_port=27016, authentication_port=8766）
- `Caves/server.ini`：Caves shard 配置（如启用 caves；server_port={{game_port - 1}}, is_master=false, name=Caves）

**建议**：在 cluster_token.txt 中明文写入"请到 https://accounts.klei.com/account/serverTokens 生成 token 后替换本文件内容"，便于用户首次部署。

### A7. 扩展 `daemon/src/instances/manager.ts` 的 vars 模板变量

当前 vars 提供：`instance_root / jvm_xmx / jvm_xms / game_port / rcon_port / rcon_password / server_name / server_hostname / server_identity / save_path / config_dir / max_players`。

**建议**：`instance_root_abs` 是关键修复——多个游戏（SteamCMD install_command）需要绝对路径。当前已有 `instance_root` 但可能是相对路径。

### A8. 扩展 `daemon/src/instances/manager.ts` 的停止逻辑支持 SIGINT 信号停止

当前 manager.ts 停止实例走 RCON 或 stdin。Valheim vanilla 不支持 RCON，必须通过 SIGINT 信号停止。

新增停止策略字段（由 pack.yaml 的 `startup.stop_method` 声明）：

```typescript
// pack.yaml startup 新增可选字段
stop_method: 'rcon' | 'stdin' | 'sigint' | 'sigterm'  // 默认 'stdin'
```

在 `stopInstance` 中根据 stop_method 分发：

- `rcon`：发送 RCON `stop_command`
- `stdin`：写 stdin `stop_command`
- `sigint`：`process.kill(pid, 'SIGINT')`（Valheim）
- `sigterm`：`process.kill(pid, 'SIGTERM')`

**建议**：Valheim pack.yaml 使用 `stop_method: sigint`，其余游戏保持现有行为。

### A9. `daemon/src/steamcmd/index.ts` 验证 downloadApp 的 anonymous 兼容性

当前 `downloadApp` 接收 appId 与目标目录，应确认：
- 调用 `steamcmd +login anonymous +app_update <appId> validate`
- 失败时抛出明确错误（不是 ENOENT）
- dyson 不在此路径中（保留 stub 模式）

**建议**：增加日志区分"anonymous 下载"与"付费账号下载"，便于运维定位。

# 第三部分：风险与限制

## 风险清单

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| Wine 依赖（enshrouded/dyson） | 服务器需预装 wine64 | deploy.sh 增加 wine 检测与安装步骤 |
| DST Cluster Token 必填 | 用户首次创建实例时无 Token → 服务器无法上线 | UI 创建表单中标注"必需"并提供获取链接 |
| Satisfactory 首次 Claim | 自动化无法绕过 | UI 提示用户首次启动后通过游戏内 Server Manager Claim |
| Valheim 三端口连续 | 用户多实例部署时端口冲突 | 实例创建时自动分配 +2/+3 端口段 |
| 多 shard DST（Master + Caves） | 单进程模式仅地表世界 | v4.1.0 暂不支持 Caves shard，UI 标注限制 |
| dyson 完全占位 | 用户期望"能运行"但实际无法运行 | UI 明确标注"占位 pack，需要手动配置" |
| 版本号 label 不准确 | staticVersions 中的版本号可能滞后于 Steam 实际版本 | 仅用于展示，不影响 SteamCMD 实际下载 |

## 限制声明

- **不修改公共契约 `public/schema/pack-schema.ts`**：已支持 13 个 game type，无需改动
- **不修改 nginx 配置**：v4.0.1 已稳定
- **不修改数据库 schema**：现有字段足够
- **不实现 DST 多 shard 部署**：v4.1.0 仅 Master shard，Caves shard 留待 v4.2.0
- **不实现自动 Wine 安装**：deploy.sh 检测但不强制安装
- **不实现 dyson 自动 mod 安装**：BepInEx + Nebula Mod 安装链路复杂，留待 v4.2.0
