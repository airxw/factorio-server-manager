## 标记体系

- `[ROUTE]`：路由或 URL
- `[API]`：接口（路径/方法/鉴权/错误码）
- `[STATE]`：页面状态（loading、error、空态等）
- `[EDGE]`：边界条件（网络失败、权限不足、重复提交等）
- `[UX]`：体验与一致性问题
- `[TODO]`：可执行待办
- `[RISK]`：风险（线上/安全/数据/回归影响）

## 强制字段约定

页面文档必须包含 11 个固定标题字段（页面定位/入口与路由/角色与权限/核心功能点/交互流程/接口与数据/状态管理与副作用/错误与边界/体验与一致性检查/关键实现定位/待办与风险），详见模板。

## 访问约束

浏览器端仅允许使用合法入口 `https://gsp.ecsrz.com:3001` 核对页面，禁止任何 `localhost:3000` / `127.0.0.1:3000` 作为浏览器访问地址。
