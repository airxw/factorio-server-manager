## 标记体系

- `[ROUTE]`：路由或 URL
- `[API]`：接口（路径/方法/鉴权/错误码）
- `[STATE]`：页面状态（loading、error、空态等）
- `[EDGE]`：边界条件（网络失败、权限不足、重复提交等）
- `[UX]`：体验与一致性问题
- `[TODO]`：可执行待办
- `[RISK]`：风险（线上/安全/数据/回归影响）
