# GSP 主页 v6 方案——动态交互式双视角演示

## 一、问题诊断（v5 反馈）

| 问题 | 根因 | 解法 |
|------|------|------|
| 演示不够动态 | 只有消息逐条出现+状态切换，缺少"活"的感觉 | 增加虚拟鼠标、打字机、按钮点击、数字跳动、页面转场 |
| 玩家/服主视角硬切割 | Tab切换导致视觉断裂、上下页断开 | 故事线自然流动：玩家旅程→旁白过渡→服主后台→双视角对比 |
| 全流程不完整 | 只展示了玩家侧5个小场景，没有服主视角 | 完整故事线：入服→礼包→商城→投票→服主Dashboard→配置→变现数据 |
| 缺少冲击力 | 演示区只是静态截图轮播感 | 自动播放"微电影"+虚拟鼠标操作+实时数据跳动 |

## 二、核心设计理念

**Story-driven Demo Theatre（故事驱动演示剧场）**
- 不是轮播截图，而是一段自动播放的"产品微电影"
- 有虚拟鼠标光标（蓝色圆点）在界面上移动、悬停、点击
- 打字机效果（游戏内聊天/控制台逐字输出）
- 数据卡片数字跳动（从0滚动到目标值）
- 页面切换有平滑过渡（fade + slide）
- 按钮点击有波纹反馈
- 有进度条指示当前故事进度
- 用户可随时暂停/切换视角/手动导航

## 四、演示剧场故事线（6个场景，约35秒一轮）

### 场景1：玩家入服（0-6秒）
- 界面：游戏内聊天窗口
- 动画：
  1. 系统消息逐字打出"欢迎 Steve 加入服务器"
  2. 停顿0.8s
  3. 礼包图标弹出+发光
  4. 系统消息逐字打出"新手礼包已发放：钻石剑×1, 金苹果×5..."
  5. 玩家消息"哇！刚进来就有装备？"
- 侧栏数据：在线人数 47→48（数字跳动）

### 场景2：商城购买（6-13秒）
- 界面：商城面板滑入
- 动画：
  1. 虚拟鼠标从左侧移动到商城区域
  2. 鼠标悬停在VIP商品上（卡片高亮+微微上浮）
  3. 鼠标点击"购买"按钮（波纹效果）
  4. 显示支付二维码（1秒）
  5. 显示"支付成功"打勾动画
  6. 游戏聊天区出现"VIP 黄金会员已激活"
  7. 玩家名前缀变化（普通→VIP金色）

### 场景3：投票踢人（13-19秒）
- 界面：半屏聊天+半屏投票面板
- 动画：
  1. 玩家Alex说"有人开挂！"
  2. Steve说"/vote kick Hacker123"
  3. 投票面板滑入：进度条从0%→100%（每秒增加一票）
  4. 5/5通过 → 系统消息"Hacker123已被踢出"
  5. 投票面板淡出

### 场景4：过渡旁白（19-22秒）
- 界面：画面变暗，居中大文字
- 动画：
  1. 聊天和商城界面模糊化
  2. 居中文字淡入："这一切，服主都不用在线"
  3. 继续淡入："GSP 在后台自动运转"
  4. 画面轻微"变焦拉远"，然后切换到服主视图

### 场景5：服主Dashboard（22-28秒）
- 界面：服主控制台仪表盘
- 动画：
  1. 顶部导航从"玩家门户"平滑变为"GM工作台"
  2. 左侧导航栏展开（Dashboard/服务器/商城/CDK/玩家...）
  3. 统计数字从0跳动到目标值：
     - 在线玩家：47
     - 今日流水：¥328
     - 活跃服务器：3
     - 今日订单：12
  4. 流水图表线条从左到右"画出"
  5. 实时事件流：Steve购买VIP ¥98 → 数字跳动+流水+¥98

### 场景6：双视角联动（28-35秒）
- 界面：分屏对比（左：玩家视角 / 右：服主视角）
- 动画：
  1. 玩家Lucy领取礼包 → 右侧"今日新玩家"数字+1
  2. 玩家Alex兑换CDK → 右侧"CDK兑换"数字+1
  3. 玩家投票通过 → 右侧"自治事件"数字+1
  4. 画面合为一体，出现大文字：
     "一个面板，连接玩家与服主"
  5. 循环回到场景1

## 五、视角切换交互

### 默认行为
- 页面加载后自动播放完整故事线（玩家→服主→双视角），循环
- 底部有视角切换胶囊："👤 玩家视角" / "🔄 完整故事" / "👑 服主视角"
- 用户点击任一胶囊，立即切换到对应视角的独立演示循环：
  - 玩家视角循环：场景1-3
  - 完整故事循环：场景1-6（默认）
  - 服主视角循环：场景5-6（从Dashboard到配置到数据）

### 切换动画
- 非硬切割：当前场景淡出（opacity 0.2s）+ 新场景淡入（opacity 0.3s）
- 虚拟鼠标移动到新场景的合理起始位置
- 进度条重置到对应视角的起点

## 六、增强动画细节

### 虚拟鼠标
- 20px蓝色圆点（box-shadow: 0 0 12px rgba(0,122,255,0.5)）
- 移动使用cubic-bezier缓动，模拟真实鼠标加速度
- 点击时缩小0.8倍+波纹圈
- 悬停在按钮上时微微放大

### 打字机效果
- 游戏聊天消息逐字输出（每个字符30-50ms，随机微小延迟模拟真实打字）
- 系统消息带[系统]前缀彩色高亮
- 消息气泡从下方滑入+轻微fade

### 数字跳动
- 使用requestAnimationFrame实现ease-out计数动画
- 从0到目标值，持续0.6-1秒
- 货币数字带"¥"前缀和千分位

### 页面转场
- 场景间过渡：当前界面fade out(0.15s) → 新界面slide up + fade in(0.3s)
- 旁白场景：全屏半透明白色遮罩+居中文字scale in
- 双视角分屏：从单屏"展开"为左右分屏（中线从中心扩展）

### 交互反馈
- 所有可点击元素有hover状态（transform: translateY(-1px) + shadow增强）
- 进度条丝滑增长（transition: width 0.3s ease）
- 播放/暂停按钮有状态变化

## 七、响应式

- **桌面(>900px)**：演示舞台最大宽度1100px，mac窗口样式，虚拟鼠标完整
- **平板(768-900px)**：舞台宽度90%，虚拟鼠标缩小到16px
- **手机(<768px)**：
  - 舞台宽度95%
  - 双视角分屏改为上下分屏
  - 虚拟鼠标隐藏（触屏设备无鼠标概念，改为直接highlight点击区域）
  - 文字大小自适应

## 八、技术约束（避免v3黑屏问题）

- **禁止**大半径blur滤镜（>20px）
- **禁止**无限循环的transform/filter动画（GPU耗尽）
- **禁止**Canvas粒子
- 使用transform/opacity做动画（GPU加速但不累积）
- IntersectionObserver控制动画只在视口内播放
-  prefers-reduced-motion：所有动画改为立即切换
- 虚拟鼠标移动用transform translate（不会引起reflow）
