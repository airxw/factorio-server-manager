# GSP 全站浅色系 Apple 风格改造方案

## 一、现状诊断

### 1.1 三个角色页面当前状态

| 角色 | 路径 | 变体 | 当前配色 | 当前风格问题 |
|------|------|------|----------|-------------|
| 玩家 | `/guild` | `variant=player` | **深色** (#000/#1C1C1E 黑底+白色文字+蓝色强调) | 纯黑电竞风，毛玻璃半透卡片，与Apple清新定位冲突 |
| 服主/GM | `/store` | `variant=store` | 浅色（slate/zinc 体系） | 传统后台灰蓝配色，#f5f6f8背景+#2563eb蓝，圆角小(8px)、阴影硬，非Apple风格 |
| 管理员 | `/admin` | `variant=admin` | 浅色（slate/zinc 体系） | 同store，传统管理后台风格，信息密度高但视觉陈旧 |

### 1.2 核心问题

1. **玩家门户深色问题**：`guild-portal.css` 整体是深色主题（`.gp-theme` 类），与"Apple清新浅色系"要求直接冲突。玩家是C端用户，深色电竞风不符合游戏社区/商城的明快消费体验。
2. **admin/store 非 Apple 风格**：虽然是浅色，但用的是传统B端后台的slate灰色系（#1f2933/#6b7280），圆角小(8px)、阴影偏硬实、字体和间距尺度不是Apple Design DNA。
3. **三套设计语言不统一**：深色玩家门户 + 传统浅色后台 = 视觉割裂，用户在角色切换（头像菜单切换工作台）时体验跳脱。

## 二、三个角色的审美定位

### 2.1 玩家门户 `/guild`（Player Portal）

**使用场景**：游戏玩家购买VIP/道具、绑定游戏角色、查看订单、发现服务器、社交互动。

**审美参照**：
- **Apple App Store** 首页：大圆角卡片、大面积留白、彩色图标渐变、轻柔弥散阴影
- **iOS 游戏中心**：明亮、活泼、沉浸式头图、游戏品牌色融合
- **移动端优先**：底部Tab导航，触控目标≥44px，卡片横向滑动

**视觉特征**：
- 背景：`#FBFBFD`（极浅灰白），分区交替 `#F5F5F7`
- 卡片：纯白 `#FFFFFF`，圆角20-24px，柔和弥散阴影（无硬边框）
- 头图区（Shop Hero）：游戏Banner图 + 底部渐变遮罩（深色到透明，保证白字可读），但Banner外围是浅色基底
- 强调色：`#007AFF` iOS蓝为主，品质色区分道具稀有度（绿/蓝/紫/橙只用于品质标签小面积）
- CTA按钮：药丸形(999px圆角)，蓝色渐变 + 轻光晕shadow
- 商城商品：卡片顶部3px品质色条（保留），但背景是白色非深色半透
- 底部Tab：白色毛玻璃顶边发丝线，激活态蓝色+顶部3px指示条

**信息层级**：
- 游戏/商品图片为主视觉，文字为辅
- 价格用高对比橙色/蓝色突出
- 状态徽章（在线/离线/已购买）小而精，彩色背景浅底深字

### 2.2 服主工作台 `/store`（GM Workbench）

**使用场景**：服主/GM查看运营数据（流水、在线人数、KPI）、配置商城商品、管理玩家、管理服务器实例。

**审美参照**：
- **Apple Business Manager / App Store Connect**：浅色专业工具，数据卡片清晰，图表清爽
- **iPad 生产力App**（Numbers/Pages）：网格布局，大量留白，字体层次分明
- 数据可视化优先：KPI数字要大、趋势图要清晰、对比色要有意义但不花哨

**视觉特征**：
- 背景：`#F5F5F7`（浅灰），内容卡片纯白
- 侧边栏：纯白/极浅灰，激活态淡蓝背景+蓝色文字+左侧蓝色竖条（非整项填充）
- KPI卡片：白色圆角20px卡片，大数字用蓝色渐变文字（`-webkit-background-clip: text`）
- 数据表格：斑马纹弱化，hover淡蓝高亮，表头浅灰字
- 图表：蓝色系折线/柱状，填充区域淡蓝渐变透明
- 状态徽章：运行中绿底浅绿白字、警告橙底、错误红底（浅底深字，非荧光色）
- 操作按钮：主要操作用蓝色填充按钮，次要操作用描边按钮

**信息层级**：
- KPI数字是视觉焦点（28-36px粗体）
- 图表占主要面积
- 侧边栏导航层级清晰，组标题小号大写灰字
- 表格信息密度适中，行高44-48px方便点击

### 2.3 平台管理后台 `/admin`（Admin Dashboard）

**使用场景**：系统管理员管理用户权限、监控系统健康、配置系统参数、查看审计日志、运维操作。

**审美参照**：
- **Apple 系统设置（macOS/iOS Settings）**：列表式布局，左侧导航+右侧内容，分组卡片
- **Server.app / Apple Configurator**：专业工具，信息密度高但不杂乱，图标统一SF Symbols风格
- **功能性 > 装饰性**：少渐变、少阴影，以边框和分组区分模块，但保持Apple圆润

**视觉特征**：
- 背景：`#F5F5F7`（浅灰），设置组用白色卡片包裹
- 侧边栏：中灰（`#F5F5F7`）基底，激活项蓝色填充+白字（macOS Settings风格）或淡蓝背景（iOS风格）
- 设置分组：白色圆角16px卡片，组标题小号大写灰字
- 表单控件：iOS风格开关、圆角12px输入框、蓝色聚焦描边
- 日志/终端：唯一保留深色区域——控制台日志区用深灰（`#1C1C1E`）背景+等宽字体+语法高亮（绿/红/蓝），与整体浅色形成功能区分
- 表格：紧凑但行高足够（40-44px），斑马纹可选，操作按钮用图标按钮

**信息层级**：
- 侧边栏导航是主要信息架构，支持折叠
- 内容区分组卡片，每组一个配置主题
- 危险操作用红色（#FF3B30）明确标注
- 数据展示用列表而非卡片（更高密度）

## 三、统一设计 Token 体系

### 3.1 核心色板（Apple 浅色系）

```css
/* 基底 */
--bg-primary: #FBFBFD;      /* 页面主背景 */
--bg-secondary: #F5F5F7;    /* 次背景/分区交替/侧边栏 */
--bg-card: #FFFFFF;         /* 卡片/表面 */
--bg-elevated: #FFFFFF;     /* 浮层/下拉 */

/* iOS 系统蓝 */
--blue: #007AFF;            /* 主强调色/CTA/链接 */
--blue-hover: #0A84FF;      /* hover态 */
--blue-light: #5AC8FA;      /* 辅助蓝/渐变终点 */
--blue-bg: rgba(0,122,255,0.08);  /* 选中/激活淡蓝背景 */
--blue-border: rgba(0,122,255,0.2); /* 蓝色描边 */

/* 功能色 */
--green: #34C759;           /* 成功/在线/增长 */
--green-bg: rgba(52,199,89,0.1);
--orange: #FF9500;          /* 警告/价格/待处理 */
--orange-bg: rgba(255,149,0,0.1);
--red: #FF3B30;             /* 错误/危险/离线 */
--red-bg: rgba(255,59,48,0.1);

/* 文字层级（Apple 四级灰） */
--text-primary: #1D1D1F;    /* 标题/正文 */
--text-secondary: #6E6E73;  /* 次要文字/说明 */
--text-tertiary: #86868B;   /* 辅助文字/占位符 */
--text-quaternary: #AEAEB2; /* 禁用/最弱化 */

/* 分割线 */
--divider: rgba(0,0,0,0.08);
--divider-strong: rgba(0,0,0,0.12);
```

### 3.2 阴影系统（Apple 弥散阴影，无硬边）

```css
--shadow-sm: 0 2px 6px rgba(0,0,0,0.04), 0 8px 24px rgba(0,0,0,0.04);
--shadow-md: 0 4px 12px rgba(0,0,0,0.06), 0 16px 40px rgba(0,0,0,0.08);
--shadow-lg: 0 8px 20px rgba(0,0,0,0.08), 0 24px 60px rgba(0,0,0,0.12);
--shadow-glow-blue: 0 4px 16px rgba(0,122,255,0.3), 0 0 30px rgba(0,122,255,0.1);
```

### 3.3 圆角尺度（Apple 圆润风格）

```css
--radius-sm: 10px;    /* 小元素：输入框/徽章 */
--radius-md: 14px;    /* 中元素：按钮/小卡片 */
--radius-lg: 20px;    /* 大卡片 */
--radius-xl: 24px;    /* 大区块/头图 */
--radius-full: 999px; /* 药丸按钮/头像/标签 */
```

### 3.4 字体排印

```css
--font-display: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'SF Pro Text',
               'Helvetica Neue', 'Noto Sans SC', sans-serif;
--font-mono: 'SF Mono', 'JetBrains Mono', ui-monospace, Menlo, Consolas, monospace;

/* 标题使用负字距 -0.02em ~ -0.03em（Apple DNA）*/
/* 正文行高 1.4-1.5 */
/* 数字等宽 tabular-nums */
```

### 3.5 道具品质色（仅用于小面积标签/色条，非大面积背景）

```css
--quality-normal: #86868B;      /* 普通：灰色 */
--quality-uncommon: #34C759;    /* 优秀：绿色 */
--quality-rare: #007AFF;        /* 稀有：蓝色 */
--quality-epic: #AF52DE;        /* 史诗：紫色（仅用于文字/标签/3px色条，禁做背景） */
--quality-legendary: #FF9500;   /* 传说：橙色（仅用于文字/标签/3px色条，禁做背景） */
```

## 四、执行步骤

### 第一步：全局 Token 统一（styles.css 重构）

**目标**：将 `styles.css` 的全局 `:root` 变量从传统slate体系升级为Apple浅色系token。

**开发事项**：
1. 替换 `:root` 中所有颜色变量为上述Apple色板
2. 更新 `--radius` 系列（默认圆角从8px提升到12-14px）
3. 更新 `--shadow` 系列为弥散柔和阴影
4. 全局字体改为 `-apple-system` 优先
5. 调整按钮基础样式：圆角更大、hover态加入微妙transform（translateY(-1px)）
6. 更新卡片 `.info-card` 样式：白卡+圆角16px+柔和阴影+细边框（1px rgba(0,0,0,0.06)）
7. 更新表格样式：表头浅灰背景、行hover淡蓝、圆角包裹
8. 更新表单输入：圆角12px、聚焦蓝色描边+3px淡蓝光晕
9. 更新徽章 `.badge` 样式：圆角999px、浅底深字、小号字体
10. 更新状态徽章颜色映射（running→绿色系、stopped→灰色系、starting→橙色系、error→红色系）

**注意**：`.gp-theme`（guild-portal.css）目前是深色且通过类名作用域覆盖全局样式，第一步不改guild-portal.css，先把默认样式（admin/store）升级为Apple浅色。

### 第二步：玩家门户浅色重构（guild-portal.css 重写）

**目标**：将 `.gp-theme` 从深色主题重写为浅色主题，消费统一Apple token但保留玩家门户的C端特色（大圆角、Bento布局、头图沉浸、横滑卡片）。

**开发事项**：
1. **重写 `.gp-theme` 下的所有CSS变量**：
   - `--gp-bg-0/#000000` → `#FBFBFD`
   - `--gp-bg-1/#1C1C1E` → `#F5F5F7`
   - `--gp-bg-card/rgba(255,255,255,0.06)` → `#FFFFFF`
   - `--gp-border/rgba(255,255,255,0.12)` → `rgba(0,0,0,0.08)`
   - `--gp-text/#FFFFFF` → `#1D1D1F`
   - `--gp-text-dim/rgba(235,235,245,0.6)` → `#6E6E73`
   - `--gp-text-faint/rgba(235,235,245,0.3)` → `#86868B`
   - `--gp-blue/#0A84FF` → `#007AFF`
   - 所有渐变从深色渐变改为浅色渐变（页面渐变从 `#000→#1C1C1E` 改为 `#FBFBFD→#F5F5F7`）
   - 阴影从深色阴影改为浅色弥散阴影
   - `color-scheme: dark` → `color-scheme: light`

2. **布局元素调整**：
   - 顶部栏 `.guild-topbar`：从黑色毛玻璃改为白色/极浅灰毛玻璃（`rgba(251,251,253,0.85)`），底部发丝线用`rgba(0,0,0,0.08)`
   - 品牌文字 `.guild-brand`：从蓝青渐变文字改为纯`#007AFF`或蓝渐变（浅底上蓝渐变文字依然好看）
   - 用户头像按钮：蓝色描边保留，背景白色
   - 下拉菜单 `.guild-user-dropdown`：白色毛玻璃+柔和阴影+细边框，替代深色毛玻璃
   - 底部Tab栏 `.guild-bottom-nav`：白色毛玻璃+顶边发丝线，激活态蓝色文字+蓝色顶部指示条
   - BUILD ID：改为淡蓝色小字（`#5AC8FA`或`rgba(0,122,255,0.5)`）

3. **卡片与组件调整**：
   - `.gp-card`：白色背景+圆角20px+柔和阴影+可选1px细边框，hover时上移2px+阴影加深
   - `.gp-hero` 头图区：保持沉浸Banner（游戏封面图+底部暗色遮罩），但hero容器外围是浅色，边框改为浅灰色
   - `.gp-shop-hero-fallback` 无Banner时的兜底渐变：改为浅色蓝色系渐变（从淡蓝到白），文字改深色
   - `.gp-shop-hero-shade` 底部遮罩：调整为从透明到浅色半透（保证白字在Banner图上可读，无字区域渐隐到白底）
   - 商品卡片 `.gp-item-card`：白色背景，顶部3px品质色条保留
   - 品质色文字：保持彩色（绿/蓝/紫/橙），但在白底上饱和度要适中
   - 按钮 `.gp-btn-primary`：蓝色渐变药丸按钮+轻光晕，保持
   - 按钮 `.gp-btn-ghost`：白底+灰色边框+灰色文字，hover浅蓝底+蓝字
   - 徽章 `.gp-badge-*`：改为浅底深字（例如emerald改绿底淡绿背景+深绿字，非荧光绿）
   - 表单输入 `.gp-input`：白底+浅灰边框+深色文字，聚焦蓝边+蓝光晕
   - 空状态 `.gp-empty`：白底+虚线边框+灰色文字
   - 骨架屏 `.gp-skeleton`：改为浅灰渐变（非深色半透）
   - 横滑容器 `.gp-hscroll`：滚动条改为淡蓝色

4. **商城商品页特殊处理**：
   - 游戏Banner图区域保留大图+底部文字，但文字区域背景从纯黑渐变改为从透明到白色半透渐变
   - 如果Banner图较暗，文字保留白色；如果Banner较亮，文字切换为深色
   - 商品列表白色卡片，品质色条在顶部，价格用橙色/蓝色突出

5. **登录页 `.login-page` 调整**：
   - 页面背景从黑色渐变改为浅色（#FBFBFD + 淡蓝色氛围光斑radial-gradient）
   - 登录卡片 `.login-card`：白色毛玻璃+大圆角+柔和阴影（非深色半透）
   - 标题蓝色渐变文字保留（浅底上蓝色渐变效果好）
   - 输入框：白底+浅灰边框
   - Demo账号按钮：三种角色对应浅蓝/浅青/浅绿背景+深色文字（非荧光色）
   - 返回按钮：白底+灰色边框

### 第三步：服主工作台 `/store` 视觉升级

**目标**：在第一步的全局浅色token基础上，强化store变体的数据驱动感和KPI视觉焦点。

**开发事项**：
1. **侧边栏调整**（Layout.tsx中store variant的sidebar）：
   - 背景：`#F5F5F7` 或 `#FBFBFD`（与页面协调）
   - 分组标题：小号大写、灰色（`#86868B`）、字距0.05em
   - 导航项：默认灰色文字，hover浅灰底，激活态淡蓝底+蓝字+左侧3px蓝色竖条
   - 折叠态：图标居中，tooltip显示名称

2. **KPI仪表盘**（运营仪表盘页）：
   - KPI卡片：白色大圆角(20px)卡片，图标用淡蓝/淡绿/淡橙圆形背景
   - 大数字：28-36px，粗体，蓝色渐变文字或深色
   - 趋势sparkline：蓝色折线+淡蓝填充
   - 同比/环比：绿色增长/红色下降小标签

3. **数据卡片增强**：
   - 流水/订单/玩家数据卡片统一视觉语言
   - 图表区域白色卡片包裹，内部边距舒适

4. **商城管理页**：
   - 商品配置表单：分组白色卡片
   - 商品预览卡片与玩家端视觉统一（白色+品质色条）

5. **玩家列表**：
   - 表格：白色圆角包裹，表头浅灰，行hover淡蓝
   - 玩家头像：圆形，蓝色边框
   - VIP标签：药丸形彩色标签（浅底深字）

### 第四步：管理后台 `/admin` 视觉升级

**目标**：在全局浅色token基础上，打造macOS/iOS Settings风格的专业工具感。

**开发事项**：
1. **侧边栏**（admin variant）：
   - 风格：macOS Settings 风格分组列表
   - 组标题：小号大写灰字
   - 导航项：图标+文字，激活态蓝色填充白字 或 淡蓝背景蓝字（统一选一种）
   - 支持折叠（已有功能）

2. **内容区设置页风格**：
   - 每组配置用白色圆角16px卡片包裹
   - 卡片内表单行分隔用细发丝线（1px rgba(0,0,0,0.06)）
   - 表单标签右对齐或左对齐统一
   - 开关控件使用iOS风格toggle

3. **系统监控页**：
   - 状态卡片：绿/黄/红状态点+文字
   - 图表区域统一白底卡片
   - 节点列表：卡片式或表格式，保持信息密度

4. **审计日志/表格页**：

## 五、关键约束与建议

1. **CSS变量驱动，禁止硬编码颜色**：所有颜色通过CSS变量消费，修改token即可全站联动。
2. **保留gp-theme作用域隔离但改为浅色**：不拆gp-theme类名，仅反转其下的变量定义，避免大面积改JSX类名。
3. **品质色紫/橙严格限用于小面积**：只允许在文字、图标、3px顶条、药丸徽章上使用，禁止作为卡片背景、按钮背景、大面积区块背景。
4. **主色绝对禁止偏紫**：蓝色锁定在 `#007AFF` / `#0A84FF` / `#5AC8FA`，渐变在这三色之间，禁止混入#8b5cf6/#a78bfa等紫色。
5. **阴影统一弥散，禁止硬边黑阴影**：所有阴影使用多层低透明度黑色，模仿Apple系统阴影。
6. **圆角全局增大**：从当前8px默认提升到12-14px默认，卡片16-20px，大区块24px。
7. **商城Banner的文字对比度**：游戏Banner图上的文字必须保证可读，使用底部渐变遮罩；但遮罩只覆盖Banner内部，不外溢到白色页面。
8. **终端/日志区是唯一允许深色背景的功能区域**：其余所有UI一律浅色基底。
9. **每完成一步就构建验证**，不要六大步一次性改完再测，避免回归困难。
10. **移动端优先**：玩家门户(/guild)所有页面必须以375px宽度为基础设计再向上适配桌面端。
