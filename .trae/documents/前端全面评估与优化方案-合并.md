> - `frontend-evaluation-report.md`

## 一、安全与核心功能修复

### 1. 移除登录页默认凭据

- 位置：`src/pages/Login.tsx`
- 步骤：
  1. `email`/`password` 初始值改为空字符串。
  2. `fillPreset` 保留供开发点击填充。
  3. 生产环境不再默认暴露管理员账号。

### 2. 路由权限守卫（RequireRole + 403 页面）

- 位置：`src/App.tsx`
- 步骤：
  1. 创建 `src/components/RequireRole.tsx`，基于 `useAuth().user.role` 控制访问。
  2. 创建 403 无权限页面 `src/pages/Forbidden.tsx`。
  3. 在 `App.tsx` 的 `/admin/*` 路由外层包裹 `RequireRole`，无权限跳 403。

### 3. 修复 RconConsole 日志重复追加

- 位置：`src/components/RconConsole.tsx`
- 步骤：
  1. 在 `wsLines.length < lastWsCount.current` 分支同步 `setDisplayLines([])`。
  2. 将 React `key` 改为稳定 ID（`line-${lineId}`），避免数组索引作 key。

### 4. 统一删除二次确认流程

- 位置：`src/pages/ServerDetail.tsx`、`src/pages/Servers.tsx`
- 步骤：
  1. 提取通用 `ConfirmDialog` 组件，支持输入名称确认模式。
  2. `ServerDetail` 删除时弹出输入实例名的对话框，校验通过后提交。
  3. `Servers` 页同步切换到统一组件，移除 `window.confirm`。
  4. 弹窗支持 ESC 关闭、点击外部关闭。

### 5. 修复 401 双重处理

- 位置：`src/api/client.ts`、`src/api/auth.tsx`
- 步骤：
  1. `request` 层统一调用 `onUnauthorized`。
  2. `AuthProvider` 中 `api.me()` 的 catch 不再清理 token，仅依赖 `createApiClient({ onUnauthorized: logout })`。

### 6. API 请求超时

- 位置：`src/api/client.ts`
- 步骤：
  1. 封装 `fetchWithTimeout`，使用 `AbortController`，默认 30s。
  2. 在所有 `request` 调用中接入 `signal`。

### 7. 清理 CreateServer 跳转定时器

- 位置：`src/pages/CreateServer.tsx`
- 步骤：
  1. 用 `useRef` 保存 `setTimeout` 句柄。
  2. `useEffect` cleanup 中 `clearTimeout`。

### 8. CreateServer 端口冲突校验

- 位置：`src/pages/CreateServer.tsx`
- 步骤：
  1. 在提交前校验游戏端口与 RCON 端口不可相同。
  2. 端口范围 1-65535 校验。

### 9. 修复登录成功跳转路径

- 位置：`src/pages/Login.tsx`
- 步骤：
  1. 登录成功后直接 `navigate('/instances')`。

### 10. Profile 编辑资料后刷新全局 user

- 位置：`src/pages/Profile.tsx`
- 步骤：
  1. `display_name` 保存成功后调用 `setUser` 或 `refreshUser()`。
  2. 头像更新也走相同路径。

### 11. RconConsole 命令无输出反馈

- 位置：`src/components/RconConsole.tsx`
- 步骤：
  1. 命令提交后若 `resp.output` 为空，显示 "(无输出)" 占位行。
  2. 失败时显示错误行并支持重发。

### 12. 路由通配符 404

- 位置：`src/App.tsx`
- 步骤：
  1. 新增 `src/pages/NotFound.tsx`。
  2. `<Route path="*" element={<NotFound />} />` 替换原重定向。

## 二、WebSocket 与实时通信

### 1. WebSocket 自动重连

- 位置：`src/hooks/useDaemonEvents.ts`
- 步骤：
  1. 引入 `useRef` 保存重连计数与 timer。
  2. `onclose` 触发指数退避重连，最多 10 次，上限 30s。
  3. 成功后重置计数。

### 2. WebSocket 心跳

- 位置：`src/hooks/useDaemonEvents.ts`
- 步骤：
  1. `onopen` 后每 30s 发送 `{ type: 'ping' }`。
  2. 60s 未收到 `pong`/`message` 主动关闭并触发重连。
  3. 后端需配套支持 `ping/pong` 消息。

### 3. WebSocket Token 安全传输

- 位置：`src/hooks/useDaemonEvents.ts`
- 步骤：
  1. 连接建立后第一条消息发送 `{ type: 'auth', token }`。
  2. 移除 URL query 方式传递 token。

### 4. WebSocket 日志环形缓冲

- 位置：`src/hooks/useDaemonEvents.ts`
- 步骤：
  1. 上限 2000 行，超限丢弃旧日志。
  2. `setLines` 中 `combined.length > 2000 ? combined.slice(-2000) : combined`。

### 5. 控制台日志虚拟化

- 位置：`src/components/RconConsole.tsx`
- 步骤：
  1. 引入 `@tanstack/react-virtual`（或 `react-window`）。
  2. 替换 `displayLines.map` 为虚拟列表。
  3. 新增"加载历史日志"按钮。

### 6. WS 消息批量更新

- 位置：`src/hooks/useDaemonEvents.ts`
- 步骤：
  1. 使用 `requestAnimationFrame` 或微任务合并多次 `setLines`。
  2. 避免高频日志触发频繁 render。

### 7. 控制台上/下键翻历史命令

- 位置：`src/components/RconConsole.tsx`
- 步骤：
  1. 用 `useRef` 维护命令历史栈与当前索引。
  2. 输入框 `onKeyDown` 拦截 ArrowUp/ArrowDown，循环显示历史。

### 8. 后台轮询暂停

- 位置：`src/components/Layout.tsx`
- 步骤：
  1. 通知轮询检查 `document.visibilityState`。
  2. 隐藏时停止轮询，可见时立即补一次。

## 十一、建议

1. **变更前先对齐契约**：任何 `public/schema/` 下的改动走 s0601 流程，避免下游实现不同步。
2. **每步可独立验证**：完成一批改动后跑 `npm run typecheck` + `npm test -- --run`，通过再继续。
3. **保护默认凭据链路**：默认凭据、`.env`、CI Secret 三处统一管理，避免部署后泄漏。
4. **WebSocket 改动后端联动**：重连、心跳、auth 消息等需后端协议配套，提前联调。
5. **大改动走 dev 分支**：UI 栈切换、React Query 迁移等保持 `main` 可部署。
6. **AGENTS.md 单一真相源**：UI 栈决策、版本号规则、目录规范与实际代码保持同步。
7. **文档驱动**：修改前在 `.trae/documents/` 留变更记录，修改后回写 note 状态。
8. **测试随功能走**：新功能/新接口必须同步补单元测试与 MSW handler。
