# v3.7.0 — 管理后台与详情页 UX 重构

**变更类型**：版本迭代（重构）
**版本号**：3.6.2 → 3.7.0
**变更日期**：2026-07-18
**影响领域**：前端 UI / pack.yaml 契约 / 路由

---

## 一、变更背景

长期版本计划（`docs/long-term-version-plan-v3.6.0-to-v4.0.0.md`）第 5 章 v3.7.0 识别出两个核心 UX 问题：

1. **实例详情页功能平铺混乱**：信息卡片不可折叠 + 13 个 Tab 全平铺 + 无状态联动 + 无移动端适配
2. **侧边栏 ADMIN_LINKS 过长**：10 项管理链接平铺，认知负荷高

本变更通过 pack.yaml `ui.tabs` 对象化、Tab 抽屉分组、状态联动隐藏、业务运营二级页面、底部固定操作栏、系统监控三 Tab 合并、侧边栏 6 分组等一系列改造，显著降低用户认知负荷。

## 二、变更内容

### 2.1 契约层（public/schema/pack-schema.ts）

- 新增 `UITabObjectSchema`：`{ key, label, group?, order?, require_state? }`
- 新增 `TabGroupSchema`：联合字面量 `runtime | config | ops | business`
- 类型拆分：`GamePackRaw`（zod 推导原始类型）vs `GamePack`（规范化后类型，`ui.tabs` 强制为 `UITabObject[]`）
- 5 个 pack.yaml 全部转为对象格式，标注 `group` / `order` / `require_state`

**状态联动规则**（plan §5.3）：
| Tab | require_state |
|-----|---------------|
| console / log-files | 全状态 |
| chat-logs / players | stopped / running / stopping / error |
| config-files | stopped / starting / running / error |
| world-gen / update / saves / mods | stopped / error only |

### 2.2 实例详情页（B1-B6）

- `pages/ServerDetail.tsx`：
  - 顶部信息卡片默认折叠为一行摘要，点击展开完整 9 行（桌面端 localStorage 记忆展开状态）
  - Tab 按四组（runtime / config / ops / business）抽屉式分组，默认展开 runtime，activeTab 所在组自动展开
  - `require_state` 不匹配的 Tab 直接不渲染，activeTab 被隐藏时自动切到 runtime 第一个
  - 底部固定操作栏（启动 / 停止 / 刷新 3 按钮），"删除"保留在顶部 page-actions
  - 切换 Tab 前若有未保存更改显示警告条

- `pages/instance-detail/Business.tsx`（新建）：
  - 业务运营二级页面 `/instances/:id/business`
  - 6 个子 Tab：商品配置 / 订单管理 / CDK 兑换 / 聊天触发 / 加入设置 / 投票踢人
  - URL 持久化 `?subtab=`，admin-only 访问检查
  - 返回按钮指向 `/instances/:id?tab=business`

- `pages/ShopOrders.tsx` / `pages/CdkRedeem.tsx`：
  - 支持 `embedded?: boolean` prop
  - embedded 模式：隐藏外层 `.page` / `.page-header` 与返回按钮（由父页面提供）
  - 独立模式：返回按钮指向 `/instances/:id?tab=business`

- `App.tsx`：注册 `/instances/:id/business` 路由（lazy load）

- `styles.css`：
  - 新增 `.business-sub-tabs` / `.tab-btn.active` / `.business-content > .page` 等样式
  - 新增底部固定操作栏样式
  - 移动端媒体查询支持水平滚动

### 2.3 管理后台合并（D1-D2）

- `pages/admin/SystemHealth.tsx`：
  - 重构为 3-Tab 结构：metrics（实时指标）/ diagnostics（一键诊断）/ disk（磁盘概览）
  - URL 持久化 `?tab=`，浏览器前进/后退同步
  - 页面标题改为"系统监控"
  - metrics Tab：CPU/内存/磁盘 + 服务状态 + 实例概览
  - diagnostics Tab：嵌入 `<Diagnostics embedded />`
  - disk Tab：节点磁盘概览
  - 刷新按钮仅 metrics Tab 显示

- `pages/admin/Diagnostics.tsx`：
  - 支持 `embedded?: boolean` prop
  - 提取 `pageActions` 和 `innerContent` 共享变量
  - embedded 模式不渲染外层 `.page` / `.page-header`

- `App.tsx`：
  - `/admin/diagnostics` 路由改为 `<Navigate to="/admin/system-health?tab=diagnostics" replace />`
  - 移除 Diagnostics lazy import（合并到 SystemHealth 内部）

### 2.4 侧边栏分组（E1）

- `components/Layout.tsx`：
  - 新增 `SidebarLinkGroup` 接口
  - `ADMIN_LINKS` 重构为 `ADMIN_GROUPS`（6 个分组）：

    | 分组 | 包含路由 |
    |------|---------|
    | 用户与权限 | /admin/users |
    | 系统监控 | /admin/system-health |
    | 配置管理 | /admin/system-config, /admin/packs |
    | 审计与日志 | /admin/audit-logs, /admin/webhooks |
    | 运维清理 | /admin/cleanup, /admin/maintenance |
    | 业务运营 | /admin/player-bindings, /admin/instance-vip |

  - 移除 `Stethoscope` 导入（不再使用）
  - render 时按分组输出，每组带 `.sidebar-group-title`
  - "系统健康" 标签改为 "系统监控"（与页面标题对齐）
  - PATH_ACTIVE_MAP：`/admin/diagnostics` → `/admin/system-health`（兼容旧 URL 重定向后激活正确菜单项）
  - 面包屑 `system-health` 标签同步更新为 "系统监控"

### 2.5 版本与文档（F1）

- 5 个 `package.json`（root / frontend / backend / daemon / version.json）版本号统一更新为 3.7.0
- `version.md` 顶部追加 v3.7.0 变更说明

  - 版本块更新（当前版本 3.7.0 + 管理后台说明 + 下一阶段 v3.8.0）
