## 一、问题分析

### 问题现象
- 用户要求按 `plan-platform-extension` 规划执行 P0 开发
- PoC 验证已通过，需要实现完整生产代码
- 需要实现 Panel + Daemon 双层架构 + Minecraft Pack + 前端 Console

### 影响范围
- 全平台：Panel Backend、Daemon、Panel Frontend、公共契约层
- 新增约 30+ 文件，修改 5+ 文件

### 根因分析
- PoC 仅验证技术可行性，生产代码需重写
- 前端骨架需要从零创建
- Daemon 实例层和协议层需要完整实现

## 二、修复方案

### 方案描述
采用 AC 范式 subagent 并行调度：
1. Daemon 核心子代理：实现 protocol/ + instances/ + pack.yaml
2. Panel Backend 子代理：实现 daemonClient/ + api/routes/
3. Panel Frontend 子代理：实现 React 骨架 + 页面 + WS hook

### 替代方案
无（并行开发是唯一高效路径）

### 风险评估
- spawn java ENOENT：无 Java 环境时实例启动失败，属于预期行为
- 类型检查：严格 TypeScript，三个子代理均报告 tsc PASS

## 四、预期效果

### 验证方式
```bash
# Daemon health
curl http://localhost:8080/health
# {"status":"ok","uptime":59,"version":"3.0.0"}

# Panel login
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@local.dev","password":"admin123"}'
# 返回 JWT + user

# Packs
curl http://localhost:3000/api/packs -H "Authorization: Bearer <token>"
# {"packs":[{"id":"minecraft-vanilla",...}]}

# Create Server
curl -X POST http://localhost:3000/api/servers \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"name":"test-mc-01","pack_id":"minecraft-vanilla"}'
# 返回 server + 分配端口

# Start Server
curl -X POST http://localhost:3000/api/servers/<id>/start \
  -H "Authorization: Bearer <token>"
# {"server_id":"...","status":"starting","pid":0}
# Daemon 收到 spawn 命令（无 Java 时 ENOENT）

# Frontend
curl http://localhost:5173
# 返回 Vite HTML
```

### 回滚方案
- 服务可通过 Ctrl+C 终止
- SQLite 数据文件 `data/panel.db` 可删除重建
- `.env` 配置可恢复默认值
