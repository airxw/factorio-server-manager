# 模块8 — 3 个 UI/UX Bug 修复

**日期**：2026-07-17
**模块**：模块8_前端应用
**版本**：3.3.3 → 3.3.4
**类型**：Bug 修复（3 个）

## 一、问题描述

1. **`net::ERR_ABORTED /api/notifications`** — 浏览器控制台持续打印 abort 错误
2. **引导第 3 步不见，导致没办法操作页面** — 首次访问 Dashboard 触发 3 步 tour，第 3 步全屏遮罩挡住页面但 tooltip 不可见
3. **手机端登出选项看不到** — 移动端地址栏未隐藏时 sidebar 内的登出按钮被挤出可视区

## 二、根因分析

### 问题 1：通知轮询 abort
- `Layout.tsx` 通知 useEffect 启动 30s 轮询，未在 cleanup 中取消 in-flight fetch
- React StrictMode + 组件重渲时浏览器自动 abort fetch → 浏览器控制台报错
- 后端 `/api/notifications` 实际返回 200，无业务异常，仅前端噪音

### 问题 2：Tour 第 3 步 tooltip 飞出视口
- Dashboard tour 第 3 步 target 为 `#app-sidebar`（`height: 100vh`，占满整个视口）
- `Tour.tsx` tooltip 定位逻辑：
  ```js
  const placeBelow = belowSpace >= 220 || rect.top < 220;
  const top = placeBelow ? rect.top + rect.height + 12 : rect.top - 12;
  ```
- 当 sidebar 占满视口时：`rect.top=0`, `rect.height=100vh` → `placeBelow=true`（`0<220`） → `top=100vh+12`（off-screen）
- 用户被全屏 spotlight 遮罩 + 不可见 tooltip 困住，唯一的"完成"按钮看不见

### 问题 3：移动端 sidebar 不滚动
- `.sidebar { height: 100vh; overflow-x: hidden; }` 无 `overflow-y`
- 移动端地址栏（状态栏）显示时视口实际高度 ≈ 60-70vh
- sidebar 高度强制 100vh → footer（登出按钮）溢出但无法滚动到
- 用户必须等地址栏自动隐藏才能看到登出

## 三、修复方案

| 问题 | 改动文件 | 关键变更 |
|------|---------|---------|
| 1 | `api/client.ts` + `api/modules/auth.ts` | `listNotifications(signal?: AbortSignal)` |
| 1 | `components/Layout.tsx` | 通知 useEffect 集成 AbortController，cleanup/visibility 切换时 `controller.abort()`，吞 `AbortError` |
| 2 | `pages/Dashboard.tsx` | tour 第 3 步 target `#app-sidebar` → `.sidebar-nav`（更聚焦） |
| 2 | `components/Tour.tsx` | 防御性增强——目标高度 >75vh 时 tooltip 改用视口居中定位 |
| 3 | `styles.css` | `.sidebar` 增加 `overflow-y: auto` |
