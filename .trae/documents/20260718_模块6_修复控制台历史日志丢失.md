## 问题诊断详情

### 根因分析

RconConsole 的日志来源仅有 WS 实时流：

```typescript
const { lines: wsLines } = useDaemonEvents(serverId);
const [displayLines, setDisplayLines] = useState<DisplayLine[]>([]);
```

- `useDaemonEvents` 在 `serverId` 变化或组件挂载时重置 `lines` 为 `[]`
- `displayLines` 是组件本地状态，卸载即丢失
- WS 协议只从订阅时刻起推送新行，不回放历史

当用户离开 ServerDetail 页面时：
1. ServerDetail 卸载 → RconConsole 卸载 → `displayLines` 丢失
2. `useDaemonEvents` cleanup → WS 关闭
3. 返回时重新挂载 → `displayLines` 从 `[]` 开始 → WS 重连 → 只收到重订阅后的新行
4. Daemon 内存环形缓冲中的历史日志从未被拉取 → 显示空状态

### 修复方案

新增历史日志拉取链路：

```
Daemon 内存环形缓冲 (logWriter.readHistory)
  ↓ GET /api/instances/:id/logs
DaemonHttpClient.getInstanceLogs()
  ↓ GET /api/servers/:id/logs (带 ownership 校验)
前端 api.getConsoleLogs()
  ↓ RconConsole useEffect (挂载时)
prepend 到 displayLines
```

时序处理：
- 历史行可能比已到的 WS 行更早 → prepend 而非 append
- WS 行在历史拉取期间可能已到达 → 历史行 prepend 到已有 WS 行之前，顺序正确
- 重复加载防护 → `historyLoadedRef` 记录已加载的 serverId，切换实例时重置
