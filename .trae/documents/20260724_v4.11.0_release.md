# 20260724_v4.11.0_release.md — v4.11.0 正式发布变更留痕

## 变更概述

v4.11.0 从"假闭合"状态收尾为正式发布。三个孤岛模块（AssetService、ExecutionEngine、Commercial前端）全部接入运行时，三基座路由架构定稿，旧业务页首批迁入，11 处版本源统一到 4.11.0。

## 变更清单

### 1. daemon 端 — 沙箱发货端点接入
- `daemon/src/server.ts`：新增 `POST /api/instances/:id/execute-logic` 端点，接收 `{ logic_string, variables }`，委托 `manager.executeLogic` → `ExecutionEngine.executeLogic` 沙箱校验后投递。
- `daemon/src/core/pack.test.ts`：修复预存在的 Instance 类型缺失字段错误（pid, started_at）。
- ExecutionEngine 此前已接入 InstanceManager（server.ts 实例化 + 注入），本次补齐 HTTP 端点。

### 2. Panel 后端 — IExecutionEngine 实现 + daemonClient 扩展
- `panel/backend/src/services/executionEngineClient.ts`（新建）：`IExecutionEngine` 的 Panel 侧实现，通过 `DaemonClientImpl.executeLogic` 转发到 daemon 沙箱。
- `panel/backend/src/services/daemonClientService.ts`：新增 `executeLogic(nodeId, serverId, logicString, variables)` 方法；`createDaemonClient` 返回类型从 `DaemonClient` 接口改为 `DaemonClientImpl` 具体类。
- `panel/backend/src/daemonClient/client.ts`：新增 `DaemonHttpClient.executeLogic(id, logicString, variables)` 低层 HTTP 调用。
- `panel/backend/src/services-init.ts`：注入 `executionEngineClient` 到服务返回对象。

### 3. 前端 — 三基座路由架构定稿 + 旧业务页迁入
- `panel/frontend/src/App.tsx`：
  - `/store` 基座承接 `/shop`、`/me`、`/versions`（URL 不变，换 StoreLayout 外壳）
  - `/guild` 基座承接 `/friends`、`/profile`、`/profile/verify`、`/profile/alerts`（URL 不变，换 GuildLayout 外壳）
  - 新增 `/store/shop`、`/store/me`、`/store/versions`、`/guild/friends`、`/guild/profile` 别名重定向
  - 剩余 `/instances/*` 实例详情页暂保留在旧 Layout 下

### 4. 版本源统一
- 11 处版本源从 4.10.1 升级到 4.11.0：
  - 根 / panel.backend / panel.frontend / daemon 的 package.json
  - version.json（4 个字段）
  - deploy.sh DEPLOY_VERSION
  - daemon/src/index.ts DAEMON_VERSION 常量
  - version.md（补写真实落地内容）
  - README.md（已为 **v4.11.0**）

### 5. 文档更新
