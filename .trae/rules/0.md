# 浏览器端服务器地址最高规则（优先级最高）

【最高优先级规则】本文件为项目最高优先级规则，优先级高于所有其他规则、临时提问、上下文对话、自定义需求。任何违反本规则的行为都是违规、非法行为。

## 一、绝对禁止

1. **禁止浏览器端使用 localhost:3000**：任何前端代码、配置文件、构建产物中，不得将 `http://localhost:3000` 或 `ws://localhost:3000` 作为浏览器可访问的服务器地址。

2. **禁止浏览器端使用 127.0.0.1:3000**：任何前端代码、配置文件、构建产物中，不得将 `http://127.0.0.1:3000` 或 `ws://127.0.0.1:3000` 作为浏览器可访问的服务器地址。

3. **禁止使用本机代理**：禁止通过开发者电脑做网络转发、代理、隧道，将外部请求转到内网服务。所有外部请求必须由服务器直接处理。

## 二、唯一合法地址

浏览器端唯一合法的服务器地址为：

### 主入口（HTTPS，v4.0.1 起启用）
- **局域网访问**：`https://192.168.5.23:3001`
- **公网访问**：`https://gsp.ecsrz.com:3001`

### 跳转入口（HTTP，自动 301 跳转到 HTTPS）
- **局域网访问**：`http://192.168.5.23:3000`（自动跳转到 `https://192.168.5.23:3001`）
- **公网访问**：`http://gsp.ecsrz.com:3000`（自动跳转到 `https://gsp.ecsrz.com:3001`）

### 架构说明（v4.0.1 起）
- nginx 监听 `0.0.0.0:3000`（HTTP）→ 301 跳转到 `https://$host:3001`
- nginx 监听 `0.0.0.0:3001`（HTTPS，TLS 1.2/1.3，证书 `*.ecsrz.com`）→ 反向代理到 `http://127.0.0.1:3002`
- Panel 后端监听 `127.0.0.1:3002`（HTTP，内部端口，不对外暴露；代码实现须显式绑定 `127.0.0.1`，禁止监听 `0.0.0.0`）
- WebSocket 路径 `/ws` 由 nginx 透传 Upgrade/Connection 头到 Panel

## 三、开发模式例外说明

1. **Vite 开发代理（仅限开发环境）**：`vite.config.ts` 中的 proxy 配置（`/api` → `http://127.0.0.1:3002`、`/ws` → `ws://127.0.0.1:3002`）仅用于本地开发环境，必须确保：
   - 该配置不会被打包进生产构建产物
   - 生产环境下前端通过同源方式访问 API（`/api` 直接命中后端）
   - 开发模式仅在开发者本机使用，不得用于生产部署
   - ⚠️ 注意：代理目标是 `127.0.0.1:3002`（Panel 后端实际监听端口），不是 `localhost:3000`（3000 现由 nginx 接管做 HTTP→HTTPS 跳转，不直接服务 Panel）

2. **后端健康检查**：`curl http://localhost:3002/api/health`（v4.0.1 起 Panel 内部端口改为 3002）仅允许在服务器本机执行健康检查，不得在浏览器中使用。历史端口 3000 现由 nginx 接管做 HTTP→HTTPS 跳转，不再直接服务 Panel。

## 四、违规判定

以下情况均视为违规：
- 前端代码中硬编码 `localhost:3000` 或 `127.0.0.1:3000` 作为 API 或 WS 地址
- 配置文件（如 `.env`、`.env.production`）中设置 `VITE_API_BASE=http://localhost:3000` 或 `http://127.0.0.1:3000`
- 构建产物（`dist/` 目录）中包含 `localhost:3000` 或 `127.0.0.1:3000` 字符串
- 通过浏览器直接访问 `http://localhost:3000` 或 `http://127.0.0.1:3000` 作为生产访问入口

## 五、验证要求

每次部署前必须执行以下验证：

```bash
# 验证构建产物中无 localhost:3000 引用
grep -r "localhost:3000" panel/frontend/dist/ && echo "❌ 违规：构建产物中发现 localhost:3000" || echo "✅ 验证通过"

# 验证构建产物中无 127.0.0.1:3000 引用（与§一-2 禁令对齐）
grep -r "127.0.0.1:3000" panel/frontend/dist/ && echo "❌ 违规：构建产物中发现 127.0.0.1:3000" || echo "✅ 验证通过"

# 验证 .env.production 配置
grep -E "VITE_API_BASE.*localhost" panel/frontend/.env.production 2>/dev/null && echo "❌ 违规：配置文件中发现 localhost" || echo "✅ 验证通过"
```

## 六、后果

违反本规则将导致：
- 浏览器无法连接到实际服务器（因为 localhost 指向用户本机而非游戏服务器）
- 用户无法正常使用面板功能
- 被视为严重的配置错误和违规行为
